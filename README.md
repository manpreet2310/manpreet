# Dr. Manpreet Singh — academic website

A compact, responsive static academic website. No build system or third-party JavaScript dependencies are required.

## GitHub Pages

Create a repository named `manpreet2310.github.io`, upload the contents of this directory to its main branch, and select **Settings → Pages → Deploy from a branch → main / (root)**. The website will be served at https://manpreet2310.github.io/.

## Editing

- `index.html`: biography, publications, research projects, funding, appointments and other academic details.
- `style.css`: layout, professional typography, color palette and responsive rules.
- `script.js`: publication search/status filters and mobile navigation.
- `assets/Manpreet_Singh_CV.docx`: downloadable CV.
- `publications.json` and `projects.json`: structured reference copies; changing these alone does not update the rendered HTML.

Research details are based on the supplied final CV, October 2026. Publication statuses are distinguished explicitly. NASA image credits and original source links are included in the page footer. Images illustrate scientific context and are not claimed as the researcher's own results.
